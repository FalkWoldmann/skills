# Contributing to litemark

Bug reports and pull requests are welcome. Please run `cargo test` and `cargo clippy` before
you open a pull request, and keep each pull request to one change.

## Machine-generated contributions

Please don't submit text or code written by an LLM or another generative tool: no generated
patches, tests, comments, commit messages, issues or pull request descriptions. Using such a
tool to find a problem is fine, as long as the fix and the words you submit are your own and
you can explain them.
